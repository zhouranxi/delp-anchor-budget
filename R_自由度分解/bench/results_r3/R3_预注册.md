# R3 预注册：conv λ 逐架构重标定——「修复不迁移」结论的 λ 归因检验

**落盘时间**：2026-11-12 00:34:03 +0800（**先于任何 R3 数据**）
**性质**：`main.tex:2616-2620` 自认的 validity threat：「The conv λ was not re-calibrated; a per-architecture sweep might restore some repair effect, though the GN-MLP control --- where the MLP-calibrated λ *is* correct --- shows the same collapse, so mis-calibration is not the whole story.」R3 把这句「might」变成测量值。素材账本 §4 剩余项之一。
**上游证据**：E5 CNN 120 runs（λ=1000=MLP 标定值、CPU、T=10、n=10）：六臂 Δell 全部 ±0.8pp 内、mnist 全 ns；fashion renorm +0.81（t=+4.4）但 Δbwt −3.93；**λ=0 与任何非 1000 的 λ 从未在 conv 上跑过**。

---

## 0. 科学问题（数据前写死）

E5 的跨架构结论「门操控在 conv 上失效」建立在**单一 λ=1000** 上。两个竞争假设：

- **H_mis（错标定）**：conv 的 Fisher/参数尺度与 MLP 不同，λ=1000 使锚过强（或过弱），掩盖了本可出现的门效应；正确标定的 λ* 能恢复部分修复效应（Δell ≥ +2）。
- **H_reg（regime 边界）**：λ 在 conv 上处于任何合理值时门效应都 ≤1pp 量级；失效来自「卷积特征 + kWTA」regime 本身，与保护强度无关。

判据见 §5。**R3 的结论无论如何都不改写 E9**（ResNet 上 renorm −8.83 独立成立，那里 λ=0.1 已按架构标定）；R3 只影响「toyCNN 上的失效是否 λ 归因」这半句话的表述强度。

## 1. 继承的协议（与 E5 CNN 逐字一致，除非本节明写）

- 架构：`cnn_delp.ConvADNet`（4 层 Conv-GN trunk + GAP → 2048 维 + dend/kWTA，`e5_arms.build_model(arch="cnn")` 逐字复用）。
- 数据：Permuted-MNIST/Fashion，T=10，`get_perms(seed,10)` 同源；EPOCHS=2、BS=256、NTRAIN=10000、Adam LR=1e-3、oracle ctx 评估。
- 锚：`make_anchor_cnn`（neuron 粒度、CE-Fisher、usage 掩码）——逐字复用。
- **设备：GPU 2/3（venv-gpu）**。E5 CNN 历史数据是 CPU——按 R2 规矩 2/3，**不做任何跨设备对齐门槛，主推断全部在本轮数据内部配对**；E5 CPU 数据仅作量级旁证（Δell ±0.8 的量级），不进任何判据。

## 2. 干预：唯一自由度是 λ

`loss = loss + λ · Σ_a anchor_penalty(a, P)` 中的 λ，取值写死为**对数轴 6 点**：

```
λ ∈ {0, 3.16, 31.6, 316, 1000, 3160}
```

- λ=0：无保护基线（E5 从未在 conv 上跑过；「锚定是否本身有害/无害」的直接测量）；
- 3.16–316：跨三个数量级的重标定轴（E9 ResNet 标定值 0.1 提示 conv 族可能需要远小于 1000 的 λ；3.16 与 31.6 覆盖该邻域，316 为中间点）；
- 1000：E5 原值（与历史旁证对齐点）；
- 3160：更强保护方向（E6 曾证 λ 是 MLP 最大主轴，Δell +8.81；若 conv 上门效应被「保护不足」掩盖，应在此显现）。

不扫 τ/α/臂——R3 只隔离 λ 这一个轴；门臂固定为 `base` 与 `renorm`（E5 的主角对）。**不动 `e5_arms.py`/`cnn_delp.py` 任何一行**，只写一个驱动脚本循环调 `run_one(..., lam=λ)`（其签名已含 lam 并落盘）。

## 3. 臂与网格

| 组 | 臂（forward） | λ 取值 | 作用 |
|---|---|---|---|
| A | `base` | {0, 3.16, 31.6, 316, 1000, 3160} | 锚强度剂量响应（门在前向） |
| B | `renorm` | 同上 6 点 | 修复臂的剂量响应（删门+1.77×） |

- 因子：2 forward × 6 λ × 2 数据集 × T=10 × 10 paired seeds = **240 runs**；分片 `job_id % 2` → GPU 2/3 各 120。
- **主要配对**：同 (ds, seed) 内跨 λ 与跨 forward 比较——全部同设备同轮次，无跨设备项。
- 预计耗时：E5 CNN 在 CPU 8 分片跑 120 runs 约数小时；GPU 单 run 约 30–60s，240 runs 双卡约 1–2 小时。

### 条件触发（写死，不默认执行）

1. **λ* 剂量加密**：仅当 §5 判 M1「部分恢复」且最优 λ* 落在相邻两点之间（两邻点效应差 >2pp）时，在 λ* 邻域 ±⅓ decade 加 2 点重跑 A/B 两臂（≤80 runs）。
2. **T=20 复制**：仅当 M1 成立时，在 λ* 上补 T=20 的 base/renorm（n=10，40 runs）——检验恢复效应是否同样受任务流长度调制（E5 的 T=20 BWT 翻转边界）。
3. **GN-MLP 复刻**：不属于本预注册（GN-MLP 对照的价值在 `main.tex:2618` 已陈述：λ 正确时同样塌陷）。

## 4. 指标

`ell / avg(final_avg) / bwt / acc_matrix` + `lam` 落盘（`run_one` 原生字段）。配对单位 (ds, seed)，n=10 per ds / n=20 pooled（与 E5/R2 口径一致，主判据按 pooled）。

## 5. 预注册判读（数据前写死）

记 `Δell(λ; fwd) = ell(fwd, λ) − ell(base, λ=1000)`（锚参照点=E5 原设置），`gain(λ) = ell(renorm,λ) − ell(base,λ)`（同 λ 内 forward 差，**主量**：门操控效应，不受锚强度共同模式污染）。

| # | 判据 | 判读 |
|---|---|---|
| M1 恢复 | ∃λ* 使 `gain(λ*) ≥ +2.0` 且 Holm 后显著（n=20 pooled） | **部分恢复**：错标定掩盖了门效应；E5「conv 失效」表述须收窄为「λ=1000 下失效」 |
| M2 边界 | 全部 6 个 λ 的 `|gain(λ)| < 1.0` 且无单调剂量趋势（Spearman \|ρ\|<0.5） | **regime 边界确认**：门效应不随 λ 恢复；`main.tex` 的「might restore」可以改写为「swept 6 decades, no restoration」 |
| M3 反转 | λ=0 时 `gain(0) ≤ −1.0`（renorm 在无保护下有害） | 锚定本身在 conv 上是 renorm 收益的必要条件——机制素材 |
| M4 锚代价 | `ell(base, 0) − ell(base, 3160)` 的符号与量级 | 锚强度剂量响应直接读数：过强保护是否压制学习（E9 plain+λ0=47.4 vs base=27.3 的 conv 版对照） |

**Holm 家族写死**：`gain(λ)` 的 6 个配对 t（每个 λ 一个，n=20 pooled）——M1 的显著性在此家族内判定。M3/M4 为单点描述，不进家族。

**判读红线**：
- M1 成立**不得**写成「DeLP 修复在 conv 上有效」——只写「λ 重标定后恢复至 +X，仍 < MLP 的 +5.48 的 Y%」。
- M2 成立是本实验的预期主结果（与 GN-MLP 对照、R2T T3 同向）；它把威胁条款变成已测量。
- 任何情况下不外推到 ResNet/transformer（E9/R4 边界独立成立）。

## 6. 统计口径

双尾 paired t + Holm（6 比较家族）；|d_z| 全报；逐 seed 方向一致性并列（混合符号记「未达严格形式」不降级）；λ 剂量趋势报 Spearman ρ（描述性）。

## 7. 实现正确性门槛（未达则数据作废、排查后重跑；只写恒等式与运行时断言）

1. **G1 λ 分派**：每条记录 `lam` 字段 ∈ 上述 6 值集合，与该 run 的调度 λ 逐位相等；`base`/`renorm` 两臂在同一 λ 下各有且仅有 10 seeds × 2 ds。
2. **G2 计数**：240 runs、无重复键 (arm, λ, ds, seed)。
3. **G3 λ=0 语义**：λ=0 的 run 必须不构造锚（`anchors` 列表为空、惩罚项恒 0）——由 `run_one` 的 `if anchors:` 分支天然保证，分析器核对 `lam=0` 组的 `bwt/ell` 非空即可（无运行时断言可加，落到驱动脚本打印）。
4. **G4 完整性**：`ell/avg/bwt/acc_matrix` 齐全，acc 矩阵 10 行下三角。
5. **G5 增量落盘**：每 run append 写盘。
6. **旁证（不进 all_ok）**：λ=1000 组与 E5 CPU 历史的 `base` 量级对照（|Δell| ≤ 5 点，仅记录跨设备差异幅度，不判 PASS/FAIL）。
