# Referenced data (bare-MLP arms)

The bare-MLP reference arms used as comparison baselines in this
paper's Table 2 / Figs 1-4 are stored here under the `s3ref_c2_*`
prefix. Provenance: they are bit-identical copies of the S1 study's
T10 dose grid (`c2_*`), kept here under an S3-owned namespace so this
folder reproduces independently -- one paper, one self-contained path.
Originals: `../../S1_剂量响应审计/results/` (this repo) or the S1
record doi:10.5281/zenodo.23637973.
