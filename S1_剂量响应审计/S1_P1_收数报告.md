## 3. 主假设判定：**不成立（如实报告）**

预注册主假设："T=10/20 上 Branch-DeLP 相对神经元级 **ℓ 显著回升、BWT 差不显著（|t|<2）**"。

实测结论：

1. **ℓ 显著回升：未发生。** 全部 6 个 (dataset, T, λ) 组合中，branch vs neuron 的 Δℓ 介于 −0.24 ~ +0.19 个百分点，|t(ℓ)| 全部 ≤1.31，无一组合显著。branch 与 neuron 在可塑性指标上**统计不可区分**。
2. **BWT 差不显著：部分违反。** BWT 方向一致偏向 branch（+0.06 ~ +0.43，即 branch 遗忘略少），但 mnist T10 两个 λ 下 |t(BWT)|>2（+2.39 / +3.95）——显著性出现在**稳定性**而非预注册的 ℓ 侧，且幅度 <0.5 pp，属边际效应。
3. **唯一的大效应在对照组：neuron ≫ plain。** plain vs neuron 的 Δℓ = −2.8 ~ −5.4 pp，|t| 高达 10~22，全组合极显著；同时 plain 的 BWT 少遗忘 2~4 pp（t 达 5~21）。这证明**粒度本身有效**（神经元级 Fisher 分流相对参数级同时提升 ℓ 与 final_avg），但**段级（branch）分流没有在神经元级之上带来可测的额外增益**。

## 4. 解读与后续建议

- 结果形态是"branch ≈ neuron ≫ plain"：粒度收益在从 plain → neuron 这一步就已兑现，branch 级进一步细分未再移动 ℓ~ln h 曲线（至少在本 P1 配置下）。
- branch 在 BWT 上有极轻微但不稳定的一致优势，方向与"更细粒度 → 每段约束更局部 → 略少遗忘"一致，但不足以作为独立主张。
- 建议论文叙事**不做粉饰、不做"branch 优于 neuron"的主张**；可选落点：(a) 把主张收敛为"粒度原则 + plain→neuron 的 ℓ 增益"，branch 作为"进一步粒度无额外收益"的边界结果；(b) 走 P3 的 ℓ~ln h 曲线分析，检查 branch 是否在**同 ℓ 下减少锚预算**（预算轴而非 ℓ 轴），这才是 branch 假设剩余的存活空间。
- 数据文件：`bench/results/s1_*.json`（5 个）；统计明细：`bench/results/s1_paired_stats.json`；分析脚本：`bench/analyze_s1.py`。

## 5. 机制诊断（人工复核，2026-10-24 20:00）

branch≈neuron 并非巧合，有两个插桩证据支撑的结构性原因：

1. **归因自限（self-limiting attribution）**：refs[k] 按 w_pk·Δ_p 追踪漂移，但 Δ_p 主要由
   罚项梯度产生，而罚项又把 W 钉在 θ_t 附近 → 归因偏移累积极小 → refs ≈ θ_t →
   branch 罚项退化为 neuron 罚项。参考的移动是罚项自己引起的位移的再分配，机制自我封顶。
2. **门控高度弥散（新测量）**：dom_hist 插桩测得 **P(神经元主导段 = 任务自有段) 仅
   2.7%–7.2%**（mnist T20 0.027 / T10 0.066；fashion 0.032 / 0.072；n=600 锚点）。
   神经元在任务上下文下的驱动段高度混合——"一个神经元一个上下文"的直觉在该架构上
   不成立，段级"参数归属"缺乏可分离载体。（原因：protect_grads 只训练自有段列，
   其余段的 ctx 列永远停在随机初始化，argmax 常被随机列赢走。）
