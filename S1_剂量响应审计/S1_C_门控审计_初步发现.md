# S1-C 门控审计：初步发现（2026-10-24 21:20）

**研究问题**：active-dendrite（ADNet）的分段（segment）在任务增量学习里到底
有没有按任务专门化？S2/S1 的用法局部化（usage localization）叙事隐含假设
"段=任务专属通道"，P1 意外测得 P(主导段=任务自有段) 仅 2.7–7.2%——本审计
把这个测量升级为研究对象，并补上零模型对照。

## 发现 1：训练使自有段胜率降到随机水平**之下**

| 网络 | P(dominant seg = own task) | 均匀随机基线 |
|---|---|---|
| 未训练 ADNet（3 seeds，T=10） | 0.096–0.111 | 0.100 |
| 训练后 P1 anchors（T=10） | **0.066–0.072** | 0.100 |
| 训练后 P1 anchors（T=20） | **0.027–0.032** | 0.050 |

训练不仅没建立段-任务对应，反而把自有段胜率压到随机之下
（T10 ≈ 0.66× 随机，T20 ≈ 0.54× 随机）。段粒度上不存在任务专门化，
存在的是**反专门化**。

## 发现 2：训练诱导强位置偏置——段 0 赢走 ~60% 神经元

| 网络 | P(segment 0 dominant) |
|---|---|
| 未训练（3 seeds） | 0.106–0.113（均匀，无偏置） |
| 训练后 P1 anchors（4 组 dataset×T） | **0.575–0.632** |

P(\|dominant − own\| = k) 分布单调递减、被段 0 主导——主导段身份与任务
身份基本无关，竞争被"富者愈富"的位置偏置接管。
（候选机制，待验证：protect_grads 只训自有列，共享 ff 权重的漂移
系统性偏向初始范数最大的上下文列。）

## 发现 3：Fisher 质量的段分布低集中度

branch 臂锚点的 Fisher 质量按段 top-1 占比仅 0.110–0.177
（随机基线 1/T：0.05–0.10）——约束质量本来就弥散在多个段上，
段归属参考（branch 臂）无从借力。与 B 判死、P1 归因自限闭环。

## 方法

- Part 1：P1 branch 臂插桩（dom_hist / seg_mass），`analyze_gating_census.py`
- Part 2：零模型 = 未训练 ADNet，与 usage_stats 完全相同的前向协议
  （任务-t 样本 × 任务-t context，kwta 活动掩码），本地 CPU 3 seeds
