## 0. 执行摘要

**H1 不成立**。即使在「保证每个加噪 run 至少发生一次错标」这一更保守的检验下，把训练期上下文/任务标签错标推进到前向、梯度掩码、usage 统计与 Fisher 锚点三处，最终精度 `avg` 的变化全部在 ±1.3 pp 以内，24 个 cell 的 Holm 校正 p 最小 **0.585**（无一显著）；剥离纯前向噪声后，锚点链路的边际代价 `Δ_anchor = fwd − full` 在 ρ=0.2 时仅 **−0.085 ~ +0.422 pp**（Holm p 0.815–1.0，`|d_z|` 0.167–0.433），四个 cell 全部命中预注册的「H1 不成立」定义（`|Δ|<1.0` 且 `p>0.05`）。

结论：**S4 的「context 通路不承重」从评估期扩展到训练期**，而且是在更强的处理强度下得到的。`main.tex:2664` 关于「训练期错误会 *differently* 污染 usage 统计与锚点」的机制推测，在本架构与规模内**没有得到支持**。

一个需要保留的细微痕迹：72 个二级比较中恰有 1 个在额外保守 Holm 后仍显著（§5.3），是 `ell` 而非 `avg`，且被 BWT 补偿抵消 —— 噪声确实进入了学习过程，只是没有传导到最终精度。

## 5. 探索性结果（只报方向，不纳入存活判定）

### 5.1 全 ρ 的 `Δ_anchor`

12 个 (ds, b, ρ) cell 的 `fwd − full` 在 `avg` 上介于 **−1.087 ~ +0.422 pp**，Holm 校正后**全部 p = 1.000**（最小原始 p = 0.159，来自 `fashion|b10|ρ0.4` 的 −1.087 pp）。`ell` / `bwt` 同样无一致方向或剂量趋势。**没有证据支持 ρ 越高锚点污染越重**。

### 5.2 24 个 cell 的主指标族

所有 `Δavg` 的 Holm 校正 p 最小 **0.585**（`mnist|b0|fwd|ρ0.1`，raw 0.024），24 个 cell **无一显著**。最大单点增益 `fashion|b10|full|ρ0.4` 为 +1.282 pp（raw 0.081，Holm 1.000）。

### 5.3 一个需要登记的二级现象

预注册主判据族是 `avg`（24 个 paired 比较）。额外做一个**比预注册更保守**的检查：把 24 cells × 3 指标 = 72 个比较一起做 Holm，只有 **1 个**仍 <0.05：

`fashion|b0|full|ρ0.2` 的 `Δell = −0.593 pp`（raw 3.35e−04，Holm₇₂ = 0.0241）。同 cell 的 `Δbwt = +0.592`（p = 0.279）、`Δavg = −0.060`（p = 0.900）；只污染前向的 `fwd` 臂对应 `Δell = −0.204`（p = 0.408）。

合理解读（**待复核，不作为结论依据**）：污染锚点让「刚学完」的对角线精度略降，同时遗忘略少，二者在最终精度上相互抵消。这是本次唯一显示噪声**确实进入了学习过程**的痕迹，而且恰好出现在 `full` 而非 `fwd`，值得在 R5 机制探针里加 Δℓ 分解去复验；但它是 72 个探索性比较中的单点，不能据此宣称「锚点链路承重」。

### 5.4 H2（训练期噪声是否改变对评估期噪声的敏感性）

`eval_rho=0.4` 减 `eval_rho=0` 的 `avg` 变化，全部在 0.1 pp 内：

| ds | clean | fwd ρ=0.2 | full ρ=0.2 |
|---|---|---|---|
| mnist | −0.124 | −0.082 | −0.067 |
| fashion | −0.081 | −0.070 | −0.082 |

训练期被污染的模型对评估期噪声**同样近乎不敏感**，方向与量级都无实质变化。按预注册只报方向，不做显著性判定。

## 9. 结论、边界与对论文的影响

### 9.1 可以写进论文的

- 训练期 context / task-label 错标（最高 ρ=0.4、平均约 3.9/10 phases 错标、保证每个 run 至少一次）对 `avg` / `ell` / `bwt` 均无实质影响；`fwd` 与 `full` 的差 ≤0.42 pp 且不显著 → **usage/Fisher 锚点链路不承重**，S4 的评估期结论在训练期成立，且证据更强。
- 这是**负结果**，但它把 `main.tex:2663-2665` 的 limitation (i) 从「未测、是 natural next experiment」升级成「已测并否证」；同时 `main.tex:1392` 关于 Δℓ 不可得的说明可以补上 R1 已提供真实 Δℓ。
- `main.tex:2664` 的 "**differently**" 机制推测（训练期错误会以不同方式污染 usage 与锚点）在本设置下**未被支持**，投稿稿不宜继续把它作为悬而未决的机制断言保留。

### 9.2 不能外推的边界

- 仅裸 MLP-ADNet / `BiasADNet`（`nh=256`）、Permuted-MNIST / Fashion、`T=10`、`n=10` paired seeds、单 `λ=1000`、单插入点。**E9 的真实骨干（ResNet-18+GN / Split-CIFAR-100）未测训练期噪声**；R4（transformer + routing）也未测。
- 噪声是 **per-phase 整体错标**，不是逐样本标签噪声；评估始终给 oracle ctx。真实部署里任务 ID 的错误形态可能不同。
- 零效应**不能**直接解释成「锚点机制鲁棒」。另一个同样成立的解释是：该实现里门值本就是常数（≈0.564）、且 per-task 掩码与前向读取粒度不一致，context 通路在结构上就无法影响学习 —— 测一个本来就是摆设的通路，当然测不出影响。R1 **无法区分这两种解释**，需要 R5 机制探针（或先修掩码）才能定论。对外口径应写「context 通路在本设置下不承重」，不要写「系统对标签噪声鲁棒」。
- 单点 `Δell` 现象（§5.3）未经独立复验，只登记不结论。

### 9.3 与工程化的关系

上一轮给的「gate_audit 诊断工具链」结论不变，但 R1 把一条边界钉死了：**在已测的裸 MLP 基座上，训练期任务标签错标不需要进入验收 checklist**（它不产生可测代价）；真正需要监控的仍是前向–梯度粒度一致性、门值常数化、以及 E9 真实骨干上的删门代价。把 R1 结论推广到医疗大模型仍须先过 R4 的 pin 哨兵。
