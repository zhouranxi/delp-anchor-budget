# R4 修订说明

## 一、开工前的三条措辞澄清（2026-11-12 09:1x，先于任何 R4 权威数据落盘；仅澄清措辞，不动任何判据与臂定义）

1. **锚点粒度（§1）**：预注册 §1 写「对角 Fisher（50 draws…）——E9 口径逐字继承」与「per-neuron 聚合同构」并存，存在张力。**实现按主导条款执行：E9 的 per-parameter 对角 Fisher + theta，penalty = Σ_k fisher[k]·(θ_k − v_k)²，全局均值归一化**（`r4_transformer.fisher_anchor` 逐字照 `e9_resnet.fisher_anchor`）。§1 的「per-neuron 聚合」句仅为语义动机的类比描述（R2/MLP 体系才是字面 per-neuron），不构成实现条款。先例依据：R2T §1 在 ResNet 上同样继承 E9 per-parameter 口径。
2. **LayerNorm 的收录（D3）**：D3 正面清单写「全部 nn.Linear（QKV/O/FFN/256→512/dend）」。实现中 `anchor_keys` 按 E9 的「backbone 全覆盖 + 排除 head」执行，故 encoder 内 4 个 LayerNorm 的 weight/bias 随收录（8K 参数，占总量 0.4%）。同构依据：E9 把 ResNet 的全部 GN 归一化参数锚定（「backbone 全局归一化」），transformer 的 LN 是其同类物。实现 99% 参数在锚内，符合「全覆盖」口径。
3. **G 的实测来源（D4）**：D4 写「argmax Δℓ 的 renorm 门均值」——措辞不准：renorm 门是 `kwta(t/G)`，不含 σ。**实际流程（E9 同款）：gprobe 阶段跑 base 门（`kwta(t·σ(d))`）的 6 runs（2ds × 3 seeds × 20 phases），G = 全部 phase-probe 的 σ(d) 均值（E[e9 的 gate_mean]），四舍五入 4 位后冻结**；随后 scan/main 使用冻结 G。E9 的 G_CONST=0.5749 即以同法测得（E9 文件头注明「pilot-measured E[sigmoid(d)]」）。

## 二、实现修订（数据前）

4. **G1 恒等式的权重向量来源（run_one）**：初版 `w = recency_weights(len(anchors), …)` 在 λ=0 的 gprobe run 上退化（λ=0 不建锚 → len(anchors)≡0 → w≡空 → Σw≡0≠v），T=3 pilot 未暴露（碰巧 base 只跑到检查软路径）、T=20 gprobe 首跑即触发 G1 断言。**修复：`w = recency_weights(phase, …)`——权重是 phase 序号的函数（phase v 持有 v 个历史锚点），与是否实际建锚无关**；λ>0 时 anchors 长度恒等于 phase，penalty 循环 `w[j]` 索引不变。R2 未暴露此问题仅因其全部 run λ=1000>0。该修复**只影响 λ=0 run 的记录字段**（λ>0 run 两种写法逐位等价），不触碰任何臂定义与判据。首跑 gprobe 的 FAIL log 留档于 `results_r4/gprobe_fail.log`。
