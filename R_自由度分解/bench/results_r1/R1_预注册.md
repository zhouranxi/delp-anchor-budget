## 2. 因果链与注入模式（本预注册的核心定义）

训练中 ctx 有**三个**作用点，已逐行核实：
1. 前向 `model(xb, ctx)` → `dend(ctx)` 选段；`BiasADNet` 用 `ctx.argmax(1)` 决定 own-segment bias 落到哪一段（`branch_delp.py:81-94`）；
2. `model.protect_grads(phase)` → 任务级梯度掩码（只传单个整数）；
3. `make_anchor(model, xs, phase, T, "neuron")` → `usage_stats` / `fisher_raw` 内部用 `task_id` 构造 ctx，决定 usage 加权与 Fisher（`branch_delp.py:114-173`）。

`main.tex:2664` 的 "**differently**" 要求把「前向噪声」与「usage/锚点污染」分开测，故设两个注入模式。**噪声模型统一为 per-phase 错标**（工程语义：某任务的上下文/任务标签整体错标，而非逐样本随机错），概率 ρ 每 phase 独立抽取，错标目标为均匀随机的**其他**任务：

| 模式 | 训练前向 ctx | `protect_grads` | `make_anchor` | 测什么 |
|---|---|---|---|---|
| `clean` | 真实 phase | 真实 phase | 真实 phase | 共享对照 |
| `fwd` | 该 phase 的 `ctx_label` | **真实 phase** | **真实 phase** | 门控前向被错上下文驱动的直接效应 |
| `full` | 该 phase 的 `ctx_label` | `ctx_label` | `ctx_label` | 追加 usage 统计污染 → Fisher 锚点错位 |

`ctx_label = phase`（未抽中）或 `randint(other tasks)`（抽中，概率 ρ）。每个 run 记录 `phase_labels`（T 个整数）与 `n_mislabeled` 以证明噪声确实生效。

**评估一律用 oracle ctx**（`eval_model(..., needs_ctx=True)`），即训练被污染、测试给正确上下文；另按 S4 口径额外跑 4 个 `eval_rho` 作桥接（见 §4）。

## 3. 网格（主实验，全部默认执行）

- 架构：裸 MLP-ADNet / `BiasADNet`，`n_h=256`、`nseg=ntask=10`、`kWTA k=64`、`protected_grads` 开启；与 S1/S4/S5 同基座，结论可直接比对。
- 固定：`λ=1000.0`（显式 `loss = loss + lam * pen`）、neuron granularity、Adam lr=LR、EPOCHS/BS/NTRAIN 同 `exp6_baselines`。
- 因子：
  - `ds ∈ {mnist, fashion}`
  - `mode ∈ {clean, fwd, full}`，其中 `clean` 只在 `ρ=0` 出现（`fwd/full` 在 ρ=0 会退化，不重复跑）
  - `ρ ∈ {0.1, 0.2, 0.4}`（`clean` 视作 ρ=0）
  - `b ∈ {0, 10}`（`BiasADNet` fixed bias；与 S4 的 E1/E2 剂量一致）
  - `seed ∈ 0..9`（paired；`get_perms(seed, T)` 与 S4 同种子）
  - `T = 10`
- **训练 run 数**：clean `1×2×2×10 = 40` + `2 modes × 3ρ × 2b × 2ds × 10 seeds = 240` → **280 runs**。
- **评估 cell 数**：每 run 产出 1 个 oracle 全相位 acc 矩阵 + 4 个 eval-ρ 最终阶段评估 → **1400 evaluation cells**。此口径写死，避免 S4 修订说明 §一 的 240→60 计数歧义。
- 分片：280 runs 按 `job_id % 2` 分给 GPU 2 / GPU 3，各写一个 JSON。

### 条件触发的追加（**不默认执行**）

1. `T=20` 复制：仅当主网格任一 `(mode, ρ, b, ds)` 出现 ≥ +1pp 的显著信号时追加（沿用 `E9_预注册.md:50-52` 的条件触发纪律）。
2. `b=3` 中间剂量：仅当 `b=10` 与 `b=0` 出现方向不一致时追加。
3. `n: 10 → 20/30`：仅当 §5 主判据落在 `p ∈ (0.01, 0.1)` 的边缘带时追加（E8 曾把边缘 null 翻成 +0.54，Holm p=0.0009）。

## 4. 指标（全部写进输出 JSON，字段名固定）

`acc = eval_model(model, xte, yte, perms, phase, T, True)` 的全相位矩阵（oracle ctx）：

- `ell = mean_{c=0..T-1} acc[(c,c)]` —— 各任务刚学完的对角线精度均值，**本次必须可得**
- `avg = favg = mean_{c=0..T-1} acc[(T-1,c)]`
- `bwt = mean_{c=0..T-2} (acc[(T-1,c)] − acc[(c,c)])`，与 `exp6_baselines.finish` 完全一致
- `final_avg_by_eval_rho`：ρ_eval ∈ {0, 0.1, 0.2, 0.4}，复用 `s4_ctxnoise.eval_noisy_final` 的 per-sample 最坏情形翻转口径，仅最终阶段
- `phase_labels`、`n_mislabeled`、`lam`、`nh`、`bias`、`mode`、`rho`、`dataset`、`seed`、`ntask`

所有 corrupted 臂与**同 (ds, seed, b) 的 clean 臂**配对。

## 5. 预注册判读（数据前写死）

### H1（R1 主判据）：锚点污染是否有边际代价

`Δ_anchor(ρ) = avg(fwd, ρ) − avg(full, ρ)`（同 ds/seed/b 配对）。它剥离了纯前向噪声，只留 usage/Fisher 链路的效应。

- **H1 成立**（训练期噪声确实经锚点链路起作用）：ρ=0.2 时 `Δ_anchor ≥ +2.0` 点，且两个数据集各自 paired `p<0.05`（Holm 校正后）；
- **H1 不成立**（锚点链路同样不承重）：`|Δ_anchor| < 1.0` 点且 `p>0.05` → 与 S4「context 通路不是 load-bearing」一致，把该结论从评估期扩展到训练期；
- **灰色地带**：如实报数值与置信区间，**不扩展主张**。

### 沿用 S4 的存活/判死判据（这次用真实 Δℓ）

- **存活 A**：ρ=0.1 时 `avg` 损失 ≤2 点、ρ=0.2 损失 ≤5 点，且两数据集逐 seed 方向一致 ≥8/10；
- **判死 A**：ρ=0.1 损失 >5 点，或 ρ=0.2 崩溃（avg<50 或损失 >10 点）；
- **存活 B**（修复存活）：ρ=0.1 时 `b=10` 相对 `b=0` 的 `Δell > 0` 且 ≥50% 的 ρ=0 增益；
- **判死 B**：ρ=0.1 时 `Δell ≤ 0`。

> **严格性条款**：S4 修订说明 §二 曾把「方向一致 ≥8/10」在符号混合时降级判通过。R1 **不得降级**：符号混合就如实记为「未达严格形式」，与幅度阈值分开报告。

### H2（探索性，只报方向，不做存活判定）

训练期噪声是否改变模型对**评估期噪声**的敏感性：比较 clean 与 corrupted 模型在 `eval_rho=0.4` 下的 `avg` 差。仅报方向与量级，不纳入多重比较（避免撑大假阳率）。

## 6. 统计口径

- 配对单位 `(ds, seed)`，`n=10`，双尾 paired t；两个数据集**不 pooling**，分别报告。
- 每个判据族内做 Holm 校正；报告绝对标准化效应量 `|d_z|`（口径同论文：均值/配对差标准差）。
- 逐 seed 方向一致性单独计数，与 p 值并列。
- `ρ=0` 的 clean 臂为共享对照，不重复计入多重比较。

## 7. 实现正确性门槛（未达则数据作废、排查后重跑）

1. 脚本中必须显式出现 `loss = loss + lam * pen`，且 JSON 记录真实生效的 `lam=1000.0`、`nh=256`（防 S4 修订说明 §四 的 λ 未生效复现）。
2. **clean 对齐校验**：`clean` 臂 `(ρ=0, b=0/10)` 的 `avg` 与 S4 `results/s4ctx_hard.*` 中同 seed、同 b 的 `final_avg_by_rho["0.0"]` 偏差 ≤0.5 点。超差即说明实现不等价，须排查后再收数。
3. ρ>0 的臂必须 `n_mislabeled > 0`，且 `phase_labels` 长度 = T；否则噪声未生效。
4. `ell`、`avg`、`bwt` 三字段全部非空；缺一即视为该 run 无效。
5. `clean` 臂按 mode 分别不重复运行（见 §3），但 `fwd/full` 在 ρ=0 不产生 run——收数报告须明确写出 run 计数口径。

**预期结论的两条分支**（写下来防止事后择优）：
- 若 H1 不成立 → 「context 通路在训练期也不承重」，S4 的零影响结论获得更强支持；DeLP 的 usage/anchor 链路对任务标签错误不敏感，本身是可报告的工程性质。
