## 1. 动机：E7 否证了「何时」，论文自己点名「保护什么」

`main.tex:1866-1869` 原文结论：

> Two interventions, two schedules, one conclusion: for interventions of this shape, gain and retention cost are one mechanism, and **the frontier has to be moved by changing what is protected, not when the intervention acts**.

E7（`E6E7_预注册.md:56-88`、`E6E7_分析报告.md:9-37`）已把「**when**」这条路走死：两个衰减调度（linear / decay-half）在 T=20 只拿到 `Δell +0.12 / +0.30`，远低于预注册要求的 `≥+4.0`；`Δbwt −0.96 / −0.49` 也未达 `≥−0.5` 的边缘线。判读原文：「收益需要整个任务流持续处于放大状态，而持续放大必然持续加速近期覆盖 → BWT 代价与收益同源」，`E6E7_分析报告.md:35-37` 明确写「renorm 的改进方向只剩两条：**与 BWT 正则联合（另开实验）**或接受其为诊断工具」。

R2 就是这「另开实验」，检验另一个自由度「**what**」。

**机制依据**（`E5_BWT_mechanism.md:57-68`，已复算）：T=20 时 renorm 相对 base 的遗忘代价**不是**早期遗忘，而是**近期/中期任务被加速覆盖**——gap 1–9 的 Δ贡献为 −2 至 −4 且全部显著，而 gap>9 的早期任务几乎不受影响（Δ≈−0.12, t=−0.30）。现有 DeLP 惩罚对所有历史锚点**等权**：`loss = CE + λ·Σ_j anchor_penalty(a_j, P, "neuron")`（`e6e7_arms.py:122-127`、`e5_arms.py:415-420`）。因此最直接的干预是：**把保护预算从早期任务重新分配给近期任务**。

**参照基线已逐 seed 复算核对**：`bench/results_e5/e5_t20_*.json` 给出 T=20 pooled（n=20）`renorm−base` 的 `Δell = +7.924`、`Δbwt = −1.607`、`Δavg = +6.398`，与 `main.tex:1843-1845`、`E6E7_分析报告.md:13` 完全一致。该数据同时用作 §7 G4 的对齐锚点。

## 2. 干预定义：总权重守恒的 recency 重分配（唯一干预）

在 phase `v`（0-indexed，训练第 v 个任务），已有锚点 `a_0 … a_{v-1}`。定义 gap `g_j = v − 1 − j`（`j=v−1` 为最近任务，`g=0`；`j=0` 为最早任务，`g=v−1`）：

```
tau   = ntask / 4                          # 固定：T=10 -> 2.5, T=20 -> 5.0
raw_j = exp(-g_j / tau)
w_j   = (1 - alpha) * 1  +  alpha * (v * raw_j / sum_k raw_k)
pen   = sum_j  w_j * anchor_penalty(a_j, P, "neuron")
loss  = CE + lam_eff * pen
```

**关键性质（写死，不得事后调整）**：

1. `Σ_j w_j = v` 对任意 `alpha`、`v` 恒成立 ⇒ 与 uniform 的**保护总强度逐 phase 相同**，纯粹是预算重分配。这条专门排除「其实只是变相调了 λ」的质疑——E6 已证明 λ 是本系统最大主轴（`Δell +8.81` / `Δbwt −3.41`）。
2. `alpha = 0` ⇒ `w_j ≡ 1`，与 uniform **逐位等价**（用作 §7 G2 的零成本实现校验，不进主网格）。
3. `alpha > 0` 时 `w_j > 0` 恒成立（指数核严格为正），不会完全放弃任何历史任务。
4. **不改**锚点构造（`make_anchor`）、Fisher、usage 统计、梯度掩码 `protect_grads(phase)`、评估协议。R1 已证锚点标签污染不承重，故此处只动惩罚的**相对权重**这一已被 E6 验证有效的杠杆。
5. `tau` 不扫描、`alpha` 只有预注册的两个非零点，避免调参自由度。

## 3. 臂与网格（主实验，全部默认执行）

| arm | 前向 | `alpha` | `lam_eff` | 作用 |
|---|---|---|---|---|
| `base` | `ADNet`（gate 原样） | 0 | 1000 | 共享对照 |
| `renorm` | `RenormADNet`，`h = kwta(t/0.565)` | 0 | 1000 | E5/E7 正方法基线（T=20 有代价） |
| `renorm_rec05` | renorm | 0.5 | 1000 | 半强度重分配 |
| `renorm_rec10` | renorm | 1.0 | 1000 | 全强度重分配（**主候选**） |
| `base_rec10` | base | 1.0 | 1000 | 加权独立效应／交互对照 |
| `renorm_lamup` | renorm | 0 | **3130** (=1000×3.13) | 只改保护**强度**、不改保护**对象**的对照 |

- 架构：裸 MLP-ADNet，`nh=256`、`nseg=ntask`、`kWTA k=25%`、`protected_grads` 开启；与 E5/E6/E7 同基座同 plumbing（`e6e7_arms.py` / `e5_arms.py` 的 `_patched_fisher_raw`、`_bd_make_anchor_dispatch`）。
- 固定：`λ=1000.0`（`renorm_lamup` 例外）、neuron granularity、Adam `lr=LR`、`EPOCHS/BS/NTRAIN/NFISHER/NUSAGE` 同 `exp6_baselines`；评估一律 oracle ctx。
- 因子：`ds ∈ {mnist, fashion}` × `T ∈ {10, 20}` × `seed ∈ 0..9`（paired，`get_perms(seed, T)` 与 E5/E6 同种子）。
- **训练 runs = 6 × 2 × 2 × 10 = 240**；分片 `job_id % 2` → GPU 2 shard 0 / GPU 3 shard 1，各 120 runs。
- **评估 cells**：每 run 每 phase 全相位 acc 矩阵，共 `240 × Σ_{p=1..T}(p+1)` 个 acc 记录；`ell/avg/bwt` 各 1 个。此计数口径写死，避免 S4 修订说明 §一 的计数歧义。

### 条件触发的追加（**不默认执行**，触发条件写死）

1. **反向加权 `renorm_anti10`**（`raw_j = exp(+g_j/tau)`，保护早期任务）：仅当 §5 H1 成立时追加，检验方向特异性。
2. **n: 10 → 20/30**：仅当 §5 主判据 pooled `p ∈ (0.01, 0.1)` 的边缘带时追加（E8 曾把边缘 null 翻成 +0.54, Holm p=0.0009）。
3. **ResNet-18+GN 迁移检验**：**不属于 R2 网格**。E9 已把 renorm（论文中称 rescale）在该骨干上打成最差臂 `−8.83`（`main.tex:1991-2004`）。若 H1 在 MLP 上成立，成文前必须另写预注册做迁移复验；R2 本身不外推到真实骨干。

## 4. 指标（字段名固定，全部写进输出 JSON）

`acc = eval_model(model, xte, yte, perms, phase, T, True)` 的全相位矩阵：

- `ell = mean_{c=0..T-1} acc[(c,c)]`
- `avg = favg = mean_{c=0..T-1} acc[(T-1,c)]`
- `bwt = mean_{c=0..T-2}(acc[(T-1,c)] − acc[(c,c)])`，与 `finish` 一致
- `acc_matrix`：长度 T 的下三角，第 p 行 p+1 列（供 §5 机制判据按 gap 分解）
- `phase_weights`：每 phase 的 `w` 向量（证明干预生效、可复算守恒）
- `arm, alpha, tau, lam_eff, ntask, ds, seed, nh, gate_const`

所有配对均在**同 (ds, seed, T)** 之间进行。

## 5. 预注册判读（数据前写死）

### H1 主判据：「改变保护对象可以移动前沿」

候选臂 `renorm_rec05` / `renorm_rec10`，阈值**逐字继承 `E6E7_预注册.md:75-79`**（E7 的成功标准），不另挑阈值：

| # | 条件 | 来源 |
|---|---|---|
| 1 | T=20 pooled (n=20) `Δell(arm vs base) ≥ +4.0` | E7 成功标准 |
| 2 | T=20 pooled `Δbwt(arm vs base) ≥ −0.5` | E7 成功标准（renorm 为 −1.61） |
| 3 | T=20 pooled `Δbwt(arm vs renorm) ≥ +1.11` 且 paired **Holm p<0.05** | 由 2 推出的必要改善量 |
| 4 | T=10 pooled `Δell ≥ +4.5` 且 `Δbwt ≥ +1.0`（不劣于 renorm） | E7 成功标准 |

- **H1 成立**：任一候选臂**四条全中** → 「when 不可行但 what 可行」，新论文以「移动前沿的正确自由度」为主结论。
- **H1 不成立**：任何一条未中 → 按 E7 的判读分支记为「**改变保护对象同样不能分离收益与代价**」，与 E7 合并为「when 与 what 两个自由度都被否证」的完整负结果。**不得**因某条接近阈值而降级判通过。
- **Holm 家族写死**：`2 个候选臂 × Δbwt(arm vs renorm)` 在 T=20 pooled 的 **2 个** paired t 检验。其余条件均为点估计阈值，不做显著性检验，不撑大假阳率。
- 主判据按 pooled n=20 报（与 E7 口径一致），同时并列两个数据集各自的 n=10 结果。

### 机制判据（探索性，只报方向，不做存活判定）

按 gap 分解 T=20 的 `Δbwt(arm vs renorm)`：若 H1 成立，改善应集中在 `gap ≤ T/2`（近期/中期），且 `gap > T/2` 不应明显变差——与 `E5_BWT_mechanism.md:62` 的代价定位对应。仅报方向与量级，不纳入多重比较。

### 特异性判据（探索性，写死以防事后解释）

1. `renorm_lamup` 若也满足条件 1–2，则即使 `renorm_rec*` 数值命中，**H1 也不得**写成「必须改变保护对象」——结论降级为「调节保护强度即可」，与 E6 的 λ 主轴一致。
2. `base_rec10` 用于估计重分配的独立效应：若其 `Δbwt` 改善 ≥ recency 臂，则效应与 renorm 的前向放大无关。

## 6. 统计口径

- 配对单位 `(ds, seed)`，`n=10` per ds / `n=20` pooled，双尾 paired t；两个数据集**不 pooling 做主推断**，pooled 仅用于对齐 E7 阈值。
- Holm 校正仅在 §5 写死的 2 比较家族内；报告绝对标准化效应量 `|d_z|`（均值 / 配对差标准差）。
- 逐 seed 方向一致性单独计数，与 p 值并列；符号混合如实记为「未达严格形式」，**不得降级判通过**（R1 §5 严格性条款）。
- `base` / `renorm` 为共享对照，不重复计入多重比较。

## 7. 实现正确性门槛（未达则数据作废、排查后重跑）

1. 脚本必须显式出现 `loss = loss + lam_eff * pen`，JSON 记录真实生效的 `lam_eff`（`base*`/`renorm_rec*` 为 1000，`renorm_lamup` 为 3130）、`nh=256`（防 S4 修订说明 §四 / E6 lam313 网格 bug 复现）。
2. **α=0 等价性**：pilot 中 `alpha=0` 分支与 uniform 参数（同 arm/ds/seed/T）的 `ell/avg/bwt` 逐位相同（`|Δ|<1e-9`）。主网格不含重复的 α=0 臂。
3. **权重守恒**：每 phase `|Σ w_j − len(anchors)| < 1e-6` 且所有 `w_j > 0`；`phase_weights` 落盘。
4. **历史对齐**：uniform 臂在 `T=10` 的 `base` 与 `bench/results_e6/e6_s*.json` 的 `base`、`T=20` 的 `base`/`renorm` 与 `bench/results_e5/e5_t20_*.json` 逐 `(ds, seed)` 比对，`ell/avg/bwt` 偏差 **≤0.5 点**（与 R1 §7.2 同口径）。超差即实现不等价，须排查后再收数。
5. `ell/avg/bwt` 三字段非空，`acc_matrix` 为长度 T 的下三角；缺一即该 run 无效。
6. run 计数 240，两分片各 120，无重复键 `(arm, ds, T, seed)`。

> **数学一致性声明（R1 教训）**：R1 §7.3 的 G3 FAIL 源于「per-phase 伯努利抽样」与「逐 run 必须至少一次错标」在 `(1−ρ)^T` 下数学冲突。本预注册**不含任何随机抽样式的逐 run 硬条款**：G2/G3 是确定性代数不变量，G4/G5/G6 是聚合对齐与完整性检查。落盘前已逐条核算在 §2–§3 定义下必然可满足；若实测未满足，即为实现缺陷，按 §7 作废重跑，**不放宽判据**。
