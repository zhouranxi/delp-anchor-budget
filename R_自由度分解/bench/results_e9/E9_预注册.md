# E9 预注册：Split-CIFAR-100 外部效度（ResNet-18+GN 五臂门操控）

**落盘时间**：2026-11-10 14:55（数据采集前）
**目的**：把 E5 终局结论——「归一化主干上门=常数阻尼、renorm 无 ell 收益、
行为差异载体是 trunk 幅度敏感度」——从 toy CNN（2 conv 层，CIFAR-10 灰度
1024 维）升级到真实骨干 ResNet-18+GN。这是 E 系列计划中最后一项实验。

## 协议（全部继承 S2 已校准的 Split-CIFAR-100 设置）

- 骨干：torchvision ResNet-18，3×3 stem 无 maxpool，BN→GN(32,C)
  （S2 round a 校准：BN running stats 在锚定下漂移，必须 GN）
- 数据：Split-CIFAR-100，T=10 任务 × 10 类，task-IL 评估（own-slice argmax）
- 训练：SGD lr=0.05, momentum=0.9, wd=5e-4, 5 epochs/task, BS=128,
  masked softmax（own 10 类 slice 上 CE，head 行零梯度）
- 锚：对角 Fisher（50 draws，max-log-softmax），backbone 全局归一化，
  **覆盖 backbone + dendritic 门模块，排除 fc head**（masked softmax 下
  head 不漂移；dend 是受训内部模块，纳入锚定）
- λ=0.1（S2 round-6 校准值）；梯度裁剪 5.0
- **门挂载**：avgpool 之后、fc 之前的 512 维池化特征层。
  `t = bb(x)`（512 维），`u = dend(ctx).view(-1, nseg, 512)`，
  `d = u.max(1)`，`h = kwta(t * σ(d), k=128)`，`out = head(h)`。
  k=128 保持 E5 的 25% 保持率（64/256）。
- ctx：任务 one-hot（训练=当前任务，评估=被评估任务自身，task-IL）

## 臂（6 个）

| 臂 | forward | 含义 |
|---|---|---|
| plain | `head(t)` | 无门无 kwta，= S2 原始模型（架构插入成本参照，lam0/lam0.1 双跑） |
| base | `kwta(t·σ(d))` | 门参与（E5 的 base 语义） |
| pin | `kwta(t·G)` | 门钉在实测常数 G |
| delete | `kwta(t)` | 去门 |
| renorm | `kwta(t/G)` | 删门+重标定（E5 主角） |
| gscale | `kwta(t·σ(d)/G)` | 保门重标定（E5c 判读） |

G = **试点实测的 E[σ(d)]**（冻结后用于 pin/renorm/gscale；预期 ≈0.56，
若显著偏离则是 0.565 普适性的第一个反例，按实测值执行并如实报告）。

## 试点（先于网格，3 seeds，GPU 0）

1. plain(lam0.1) vs base(lam0.1)：base 精度若低于 plain 2pp 以上 → kwta-128
   破坏性过强，k 升至 256 重试；base 可用（差距 <2pp）→ 冻结协议
2. 实测 G 与门分布（sd、q10–q90、逐 phase 演化）+ t_absmean(feat)
3. 单 run 时长实测 → 估算网格时长

## 网格（试点通过后启动，GPU 0/2/3 三卡）

- T=10：6 臂（plain 只跑 lam0.1）× 10 seeds = 60 runs；另 plain(lam0) 10 runs
  作无保护参照 = 70 runs
- E5 已在三个架构确立 BWT 翻转规律，T=20 的 base/renorm/plain（30 runs）
  列为**可选追加**：仅当 T=10 上 renorm 出现任何 ≥+1pp 的信号时跑
  （若无信号，T=20 的翻转检验没有增量信息，不值得 30 个 GPU 时）

## 预注册判读（数据前写死）

| # | 假设 | 判据（T=10，配对 n=10，双数据侧不 pooling——CIFAR 只有一个数据集） |
|---|---|---|
| H1 主 | renorm−base Δell ≈ 0（归一化主干边界推广到真实骨干） | \|Δell\| < 1pp 且 p>0.05 |
| H2 | pin≈base（门=常数阻尼，可钉死） | \|Δell\| < 1pp |
| H3 | gscale≈renorm≈delete（幅度是唯一杠杆） | 三者两两 \|Δ\| < 1pp |
| H4 | 门分布普适：E[σ(d)]∈[0.50,0.65]，sd<0.05 | 逐 phase 平坦 |
| H5 | t_absmean(feat) 小（归一化钳制幅度，机制载体） | ≪ 2（MLP 的下限） |

**否证条款**：若 renorm−base ≥ +2pp 且显著 → 「归一化主干上 renorm 无效」
边界**不**推广到真实骨干，E5 的边界主张必须收窄为「小规模 conv-GN」，
论文闭环章节的表述相应修改。这是本实验最重要的可能输出——正反结果都可发表。

**次要预期**：plain−base 差值给出「插入 kwta+门」本身的架构成本，
若成本大（>2pp）需在报告中声明所有门操控结论以 base 为参照系。

## 事故预案

- GPU 2/3 被 Stu1 任务挤压 OOM → 自动降级为 GPU 0 双分片串行
- base 精度崩（<35%，S2 的 plain T=10 参考 ≈55-65%）→ 停网格，排查 kwta
- 门分布 sd > 0.1（宽门）→ 如实记录，0.565 普适性第四架构反例，同样可发表
