## 0. 科学问题（数据前写死）

新论文目前的「architecture-bound supply」主张基于两个架构点：MLP（R2：预算方向有效，T20 Δℓ vs base +8.08）与 ResNet-18+GN（R2T：T3 fail，+0.72 n.s.）。两个点无法区分「MLP 特有」与「递减/随机边界」。R4 在第三个家族——**注意力骨干**——上重复同一干预，把边界从二分线变成趋势。

> **当骨干换成 Transformer（门控方式与 E9 同构：dendritic gate 挂在池化特征上）时，只重分配锚点预算方向（不动前向）能否改善 gain–retention 前沿？**

三个结局都预写判读（§5），无事后择优空间。本实验**不追求**「transformer 上的 SOTA 持续学习」——只检验「预算方向」这一自由度在注意力参数化下是否仍是有效杠杆。

## 1. 骨干与任务协议（与 R2 逐字对齐，除非本节明写）

- **任务**：Permuted-MNIST / Permuted-Fashion，`get_perms(seed, T)`（`exp6_baselines` 同源），`T ∈ {10, 20}`，task-IL 评估、oracle ctx——与 R2 的 `(ds, T, seed)` 因子**逐字相同**，使 R2 的 MLP 网格可作为并列参照（**跨架构只并列、不做统计配对**）。
- **骨干（D1 已回填 = A）**：
  - **A（推荐）**：`TransformerEncoder` 2 层、`d_model=256`、4 heads、FFN 1024、GELU、learned position embedding（28 行 token，每行 28 维像素线性投影到 256）；序列 = 28 行；mean-pool → 512 维特征（一层 Linear 256→512）。
  - B：4 层 d=128（参数量相近，深度换宽度）。
- **门（与 E9 同构，逐字映射）**：池化特征 `f ∈ R^512` → `d = max_seg(dend(ctx))`（`dend: ntask → nseg*512`）→ base 门 `h = kwta(t·σ(d), k=128)`（25% 保持率）/ renorm 门 `h = kwta(t/G, k=128)`；head：Linear(512→10)。
- **锚点覆盖（D3 已回填：全部 `nn.Linear`（QKV/O/FFN/256→512 投影/dend），排除 head 与 position/输入 embedding**）。理由：transformer 的「neuron」语义 = FFN unit / attention output channel，挂在 Linear 权重行上与 MLP/E9 的 per-neuron 聚合同构；embedding 是查表，不是保护性线性层。对角 Fisher（50 draws，max-log-softmax，one-hot ctx）、全局归一化——E9 口径逐字继承。
- **训练超参（全部继承 R2 的 MLP 协议，最小变量原则）**：Adam lr=1e-3、`EPOCHS=2`/task、`BS=256`、`NTRAIN=10000`/task、评估 oracle ctx；无 dropout（与 MLP 协议一致，不引入新随机源）。
- **G（D4 已回填）**：标定阶段实测后冻结（§2），机制同 R2T（renorm 门用冻结 G，pin/base 门用 σ）。

## 2. 两阶段流程：先标定、后主实验（R3 教训的落地）

**R2T 只用了上游单点 λ=0.1，R3 证明单点标定会落在剂量曲线的任意点上。R4 无上游校准值，故标定是预注册的一部分。**

### 阶段一：λ 标定扫描（runs = 6λ × 2臂 × 2ds × 5seeds = 120）

- λ ∈ {0, 0.1, 1, 10, 100, 1000}（10 进制对数网格；λ=0 从未在该骨干跑过，必含）。
- 臂：{base, renorm}；T=20、seeds 0–4。
- **λ* 选择准则（写死）**：λ* = argmax_λ Δℓ(renorm vs base)（pooled 10 runs）。整条曲线**全部落盘并进论文**（R3 条款：非单调即披露第二谷）。
- **特殊分支（写死）**：若全网格 Δℓ(renorm vs base) ≤ 0（renorm 前向在 transformer 上全面有害，即 E9 情形重演）→ λ* = argmin_λ |Δℓ|（最小伤害点），且主实验的**主候选自动切换为 `base_rec10`**（R2T 的 C1 逻辑），C2 降为次要；此切换本身写进修订说明。
- 标定阶段的数据**不进主判定**（除 λ* 选择外）；若主实验某臂在 λ* 处与标定阶段配置完全相同（同臂同 λ 同 seed），该 5 seeds 可并入主网格并在数据中标记来源。

### 阶段二：主实验（runs = 5臂 × 2ds × 20seeds × T=20 = 200）

| arm | 前向门 | α | reverse | 作用 |
|---|---|---|---|---|
| `base` | `kwta(t·σ(d))` | 0 | — | 共享对照 |
| `renorm` | `kwta(t/G)` | 0 | — | renorm 基座 |
| `base_rec10` | base | 1.0 | 否 | **主候选**（不动前向，只重分配） |
| `renorm_rec10` | renorm | 1.0 | 否 | R2 主候选的完整迁移 |
| `base_anti10` | base | 1.0 | 是 | 方向对照（保护早期） |

- 干预定义**逐字复用** `r2_recency.recency_weights`（τ=T/4=5.0，总权重守恒 Σw=v，α=0 ⇒ w≡1，反向取 exp(+g/τ)；`phase_weights`/`weight_sums` 落盘）。
- T=10 网格**不默认跑**（R2T 先例：T=10 无信号则 T=20 无增量；若主判定落在边缘带则按 §3 触发条款 2 处理）。
- 分片：GPU 2 / GPU 3 `job_id % 2`；**显存上限 8%/进程、不触碰他人进程**（R2 同款纪律）。

### 条件触发（写死，不默认执行）

1. **剂量轴**：主臂 α∈{0.25, 0.5}，仅当 C1 Δ 95%CI 跨 0 且方向为正时追加（判断剂量不足 vs 机制失效；3 档 × 2ds × 10 seeds = 60 runs）。
2. **n 扩到 30**：任一主比较 raw p ∈ (0.01, 0.1) 时追加（E8/R2T 双先例条款），新增 10 seeds/臂。
3. T=10 网格：仅当 T=20 判读为 T1/T2 时追加（补 R2 的条件 4 对应口径）。

## 3. 主比较与判读（数据前写死；三层结构继承 R2T）

**主比较家族（预注册）**：C1 = `base_rec10` vs `base`、C2 = `renorm_rec10` vs `renorm` 的 **Δℓ 与 Δbwt（4 个 paired t，Holm 校正）**。配对单位 `(ds, seed)`，n=40 pooled（20 seeds × 2ds）——**注意与 R2 的 n=20 pooled 口径不同（本实验 T=20 单口径、双数据集全 pooling），系 R2T 单数据集口径向双数据集的自然扩展，效果量按原始单位解读并并列两数据集分列**。
描述性（不进家族）：C3 = `base_anti10` vs `base_rec10`（方向特异性）、C4 = `base_rec10` vs `renorm`（「改方向」vs「改前向」）。

**三层判读（阈值逐字继承 R2T §5）**：

- **T1「transfer」**：C1 Δℓ>0 且 Δbwt>−1.0 且 Holm 后 C1.ell p<0.05 → 「预算方向自由度迁移到注意力骨干；architecture-bound 的边界在 MLP 与 transformer 上打开、ResNet 上关闭」。
- **T2「rescue」**：C1 不达但 C2 达标 → 「仅 renorm 基座内有效（基座×预算交互 story，与 R2 的 base_rec10 无 gain 呼应）」。
- **T3「fail」**：均不达 → 「三个架构两个 fail（ResNet、Transformer）或全部失效；supply 的 MLP-only 性进一步加固」。
- **方向特异性（探索性）**：C3 若 anti 的 bwt 显著差于 rec10 → 方向特异性在第三架构成立；**逐 seed 方向计数与 p 并列，混合符号如实记「未达严格形式」，不降级**。

**判读红线**：
- 任一层级不改写 R2/R2T 结论；三架构结果并列陈述。
- 效果量按原始单位 + 相对基线比例双报（R2T 红线同款：transformer 的 ℓ 基线与 MLP 不同）。
- **不写成「通用持续学习改进」**：适用范围限定「本协议 2 层 Transformer / Permuted-MNIST/Fashion / task-IL / λ*（本实验标定）/ T=20 / n=40」。

## 4. 指标（字段名与 R2/R2T 一致）

`ell`、`avg`、`bwt`、`acc_matrix`（下三角 T）、`gate_stats`、`phase_weights`（round 6）、`weight_sums`、`arm/alpha/tau/lam_eff/g_const/nseg/d_model/n_layers`。标定阶段另记 `lam_scan` 字段。

## 5. 统计口径

- 配对 t（双尾）+ Holm（4 比较家族）；|d_z| 一律报告；逐 seed 方向一致性计数并列。
- 两数据集 pooling 做主推断（n=40），**同时并列**各自 n=20 的分列结果（R2 §6 的双报条款扩展版）；若分列方向相反，如实报告并以分列为准解读。
- 功效核算（数据前写死）：R2 实测同前向配对差 sd≈1.2（ℓ）；transformer 预计更噪，按保守 sd=3：n=40 可检出 |Δ|≥0.95 pp（α=0.05，power≈0.8）——R2 效应量（+8.08/+1.52）若缩水 3 倍仍在检验阈内；若缩水 10 倍则按 T3 判 fail 并如实报告功效限制，不扩样本硬凑显著（扩样本仅按 §2 触发条款 2）。

## 6. 实现正确性门槛（未达则数据作废、排查后重跑；全部为数学恒等式/运行时断言，无跨运行逐位条款）

> **总则（R2T 教训固化）**：transformer 的 matmul 同样受 cuDNN 非确定性影响，**不设任何依赖训练结果逐位复现的门**。历史对齐门（R2 G4）在此**不可用**（无同骨干历史数据）——以 G2/G3 恒等式 + G6 统计带替代，此替代本身写进预注册。

1. **G1 权重守恒（恒等式）**：每 run 每 phase `|Σw_j − v| < 1e-6` 且所有 `w_j > 0`；`phase_weights` 完整落盘。
2. **G2 α 分派与镜像（恒等式）**：落盘 `alpha` 与臂名一致；anti 的 `w[0] > w[-1]`、非 anti 的 `w[0] < w[-1]`；`recency_weights` 与 `r2_recency.py` **逐字同源**（import 复用，不允许重写）。
3. **G3 α=0 代码等价（构造性检查，非训练检查）**：`alpha=0` 时 `recency_weights` 返回的权重数组与全 1 向量逐位相同（`|Δ|<1e-12`）——在 pilot 中对该函数直接断言，不跑训练。
4. **G4 运行时断言**：`loss = loss + lam_eff * pen_weighted` 的 `lam_eff` 落盘（标定=扫描值；主实验=λ*）；`d_model=256`、`n_layers=2`、`EPOCHS=2`、`BS=256`、`NTRAIN=10000` 写死并落盘（防 E6 lam 分派 bug 复现）。
5. **G5 增量落盘**：每 run 完成即 append 写盘。
6. **G6 门统计合理带**：`gate_mean` ∈ [0.50, 0.65] 且 sd < 0.05（E9/R2T 同窗口）；超出先排查实现再收数。
7. **G7 标定-主实验一致性**：主实验 `base`/`renorm` 在重叠 seeds（0–4）上的均值与标定阶段同配置均值差 ≤1.5 pp（跨运行非确定性容差，参照 R2T D 探针量级的宽松版）；超差说明两阶段实现漂移，排查后重跑**两阶段**。
